## Looping Through a List 

The first big idea in this chapter is the **for loop** and it lets you go through each item in a list one at a time.

```python 
magicians = ['alice', 'david', 'carolina']

for magician in magicians:
    print(magician)
# python takes one item at a time and assigns it to `magician`
```
### Step by step what is happening here? 
- ```python magicians = ['alice', 'david', 'carolina']``` this creates a list called `magicians` that has 3 items: `'alice'`, `'david'`, and `'carolina'`
- ```python for magician in magicians: ``` this is the start of the loop. This line tells Python "Take one item at a time from the list called `magicians` and for each item, temporarily call it `magician`." 
- That means: first time through the loop, `magician` = `'alice'`, second time - `magician` = `'david'`, third time - `magician` = `'carolina'`

## How to Think About a Loop 
```python
for magician in magicians:
```
Basically translates to "For each magician in the list of magicians..." 
- `magician` = temporary variable 
- Runs once for each item 

---

## Doing More Inside a Loop 
```python
for magician in magicians: 
    print(f"{magician.title()}, that was a great trick!")
```
You can run multiple lines for each item. 

---

## Indentation (VERY IMPORTANT)
Indentation tells Python what belongs _inside_ the loop. 
```python
for magician in magicians: 
    print(magician)

print("Done!")
```
- Indented --> runs repeatedly 
- Not indented --> runs once

---

## Common Errors
### Missing indentation
```python
for magician in magicians: 
print(magician)
```
This will print IndentationError. 

### Missing Colon
```python
for magician in magicians
```
This will print SyntaxError

### Logical error (runs but wrong)
```python
for magician in magicians:
    print(magician)
print("Great show!")
```
Here the last line is running only once, when we intended to run per item in list.
